\chapter*{關於本講義}
這些由不同編者獨立編輯的配套講義，依據 Leonard
Susskind 的講課內容整理而成。講義根據機器轉錄稿、字幕
及部分黑板畫面重建，並對照可取得的原始資料加以核對。
這些講義並非 Susskind 教授親撰的原稿，
也未經他審閱或認可。

本版由 \href{https://lazying.art}{LazyingArt LLC}
採用開源的
\href{https://github.com/lachlanchen/Video2Book}{Video2Book} 工作流程編製。
機器轉錄稿另行提供，其中可能含有
辨識錯誤。編輯上的澄清及較大幅度的
重建均以腳註標示。
